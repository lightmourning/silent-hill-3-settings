# Silent Hill 3 на Steam Deck и ПК

Установщики настроек для своей копии Silent Hill 3. В обоих архивах есть README на русском.

- [Steam Deck](https://github.com/lightmourning/silent-hill-3-settings/releases/latest/download/SH3-Steam-Deck.zip): распакуй, открой терминал в папке и выполни `bash install-deck.sh`.
- [Windows](https://github.com/lightmourning/silent-hill-3-settings/releases/latest/download/SH3-Windows-PC.zip): распакуй и запусти `install-windows.cmd`.

Установщики загружают нужные компоненты и применяют саундфикс к звуковым эффектам. Перед заменой сохраняется копия файлов в `sh3-settings-backup`.
