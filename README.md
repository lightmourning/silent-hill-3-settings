# Silent Hill 3 на Steam Deck и ПК

Настройки для своей копии Silent Hill 3. Каждый архив содержит отдельный README на русском.

- [Steam Deck](https://github.com/lightmourning/silent-hill-3-settings/releases/latest/download/SH3-Steam-Deck.zip): скрипт запуска, настройки 1280×800 и DXVK.
- [Windows](https://github.com/lightmourning/silent-hill-3-settings/releases/latest/download/SH3-Windows-PC.zip): настройки Widescreen Fix для 1920×1080.
